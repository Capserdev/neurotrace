Datasets
📺
PC-GITA
Voice training data
  • Clinical voice corpus used to train and validate the SVC-based voice models. Contains sustained vowels, connected speech, and spontaneous recordings from Parkinson's disease patients and healthy controls. Features jitter, shimmer, harmonicity, formants, and nonlinear dynamics across 36 acoustic dimensions.
✏️
HandPD
Handwriting training data
  • Handwriting drawing dataset used for fine-tuning EfficientNetV2B0 on meander, spiral, and wave drawing tasks. Captures motor control differences between healthy controls and Parkinson's disease patients through standardized pen-on-paper drawing tests.
🌎
ImageNet
Pre-training source
  • Large-scale image database (14 million+ images, 20,000 categories) used to pre-train the EfficientNetV2B0 backbone. Weights sourced from tf.keras.applications.EfficientNetV2B0(weights='imagenet') via TensorFlow/Keras.
Machine Learning & Deep Learning
🧠
TensorFlow / Keras
Deep learning framework
  • tensorflow-cpu End-to-end deep learning platform used to load and run all three handwriting classification models. 2.17.0
  • EfficientNetV2B0 Convolutional neural network architecture pretrained on ImageNet, fine-tuned for PD vs HC handwriting classification. 3 separate models for meander, spiral, and wave drawing tasks. Includes built-in Rescaling + Normalization preprocessing (include_preprocessing=True). 4× test-time augmentation (original, h-flip, v-flip, 90° rotation).
  • Grad-CAM Gradient-weighted Class Activation Mapping used during research to generate visual explanations of which drawing regions influenced predictions.
📈
scikit-learn
Classical machine learning
  • scikit-learn Support Vector Classifier (SVC) pipelines used for all four voice models: PD vs HC (AHH), PD vs HC (vowels), PD vs HC (text), and 4-class HC/PD/PSP/MSA. 1.5.2
  • joblib Model serialization library used to save and load all four trained SVC pipelines (.joblib files). 1.4.2
Audio & Signal Processing
🎤
Praat / parselmouth
Acoustic analysis engine
  • praat-parselmouth Python wrapper for Praat — the leading phonetics research software. Used to extract all 36 acoustic features from voice recordings: jitter (5 measures), shimmer (6 measures), harmonicity (3 measures), intensity (min/max/mean), formants F1–F4 and bandwidths B1–B4, glottal/GNE approximations, and nonlinear dynamics (PPE, DFA, RPDE). 0.4.3
  • Praat (core software) Developed by Paul Boersma & David Weenink, University of Amsterdam. The gold standard for phonetic analysis used in clinical and research settings worldwide.
🔢
Scientific Computing
Numerical libraries
  • NumPy Fundamental array computing library used throughout feature extraction, image preprocessing, TTA averaging, and ensemble probability calculations. 1.26.4
  • SciPy Scientific computing toolkit providing additional numerical routines used alongside feature extraction and signal processing. 1.13.1
Backend & API
⚡
FastAPI
Web framework
  • FastAPI High-performance Python web framework powering the NeuroTrace API. Handles /predict/voice, /predict/drawing, and /predict/ensemble endpoints, static file serving, and CORS. 0.115.0
  • Uvicorn ASGI server used to run the FastAPI application. Deployed on port 7860 within the Docker container on Hugging Face Spaces. 0.30.6
  • python-multipart Multipart form data parsing, enabling file uploads (audio and image) through the browser frontend. 0.0.9
📷
Image Processing
Pillow
  • Pillow (PIL) Python imaging library used to decode uploaded drawing images, convert them to RGB, and resize to 224×224 using LANCZOS resampling before passing to the handwriting models. 10.4.0

Web standards
