Model Architecture
Handwriting Models — EfficientNetV2B0 Backbone
94.59% Accuracy

Meander Model

Architecture: EfficientNetV2B0 (ImageNet, frozen) → Input(name=“img”) → preprocess_input → GlobalAveragePooling2D → Dropout(0.4) → Dense(256, ReLU, L2=1e-4) → Dropout(0.4) → Dense(1, sigmoid).

Training: Phase 1 — head only, Adam(1e-3), 6 epochs, EarlyStopping(patience=4), ReduceLROnPlateau(factor=0.3, patience=2). Phase 2 — backbone unfrozen (BatchNorm kept frozen), Adam(1e-5), 6 epochs.

Dataset: HandPD (MeanderControl / MeanderPatients), 80% temp → 85% train / 15% val, 20% test. No augmentation.

Results (N=74): Accuracy 94.59%, F1=0.91, PD F1=0.97. Confusion: [[12,2],[2,58]].

90.00% Accuracy

Spiral Model

Architecture: Same backbone + Dropout(0.3) + Dense(256, L2=5e-5). Augmentation pipeline (no flips): RandomRotation(0.12), RandomZoom(0.12), RandomTranslation(0.08, 0.08).

Training: 2-model ensemble (seeds 42 & 123). Phase 1 — Adam(1e-3), label_smoothing=0.01, 20 epochs, EarlyStopping(patience=6). Phase 2 — Adam(3e-5), 15 epochs. Threshold tuned via val-set sweep (0.2–0.8).

Inference: 4-pass TTA — original + h-flip + rot90 CCW + rot90 CW, averaged.

Dataset: HandPD spirals + Archive-3, handwriting oversampled 3×; 80/20 split.

Results (N=90): Accuracy 90.00%, F1=0.90. Confusion: [[42,3],[6,39]].

93.33% Accuracy

Wave Model

Architecture: Same backbone + Dropout(0.4) + Dense(256, L2=1e-4). Broader augmentation: RandomRotation(0.10), RandomZoom(0.10), RandomTranslation(0.08, 0.08), RandomContrast(0.10), RandomBrightness(0.10).

Training: Single model. Phase 1 — Adam(1e-3), label_smoothing=0.01, 20 epochs, EarlyStopping(patience=8). Phase 2 — Adam(2e-5), 15 epochs.

Inference: 4-pass TTA identical to Spiral.

Dataset: HandPD wave + Archive-3 wave, HW oversampled 3×; 90/10 split.

Results (N=90): Accuracy 93.33%. Confusion: [[42,3],[3,42]].

Voice Models — SVM Pipeline (StandardScaler + RBF SVC)
AUC 0.967

AHH Model

Binary PD vs HC on sustained “ahh” phonation.

Pipeline: StandardScaler → SVC(kernel=rbf, probability=True).

Tuning: GridSearchCV — C∈{0.1,1,10}, γ∈{scale,0.1,0.01}, cv=5.

Dataset: PC-GITA HC_AH + PD_AH directories.

Features: 36 acoustic features (13 MFCC means + 13 stds + ZCR + spectral + RMS).

AUC 0.932

Vowels Model

Binary PD vs HC on sustained vowel sounds.

Pipeline: Same as AHH — StandardScaler → SVC(rbf, probability=True), GridSearchCV cv=5.

Dataset: speakers-with-parkinsons-and-parkinsonism, filtered to HC/PD labels inferred from filenames.

Split: 80/20 stratified train/test.

Features: Same 36-feature vector.

AUC 0.852

Text Reading Model

Binary PD vs HC on continuous speech (North Wind passage).

Pipeline: StandardScaler → SVC(rbf, class_weight={0:1.0, 1:2.0}). PD weighted 2× to boost sensitivity. GridSearchCV — C∈{0.3,1,3,10,30}, γ∈{0.001…0.1}.

Dataset: KCL ReadText HC/PD (26-29_09_2017). First 30s skipped (task instructions).

Features: Same 36-feature vector extracted from speech after 30s offset.

4-Class

4-Class Vowel Classifier

Classifies into HC / PD / PSP / MSA from a single vowel recording.

Pipeline: StandardScaler → SVC(rbf, probability=True, decision_function_shape=“ovr”, class_weight=“balanced”).

Tuning: StratifiedKFold(5), wider grid — C∈{0.3,1,3,10,30}, γ∈{scale,1,0.3,0.1,0.03,0.01}.

Dataset: speakers-with-parkinsons-and-parkinsonism, all four classes.

Output: Probability vector [HC, PD, PSP, MSA].
